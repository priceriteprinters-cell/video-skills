# Video Skills (combined)

This folder bundles three sub-guides. Pick one, then read its `GUIDE.md` and treat that sub-folder as its root (any "SKILL.md" it mentions means its `GUIDE.md`; relative paths like `references/...` resolve inside that sub-folder).

| Task | Read |
| --- | --- |
| Full narrated production end-to-end: brief, fonts/palette, transcription, scene timing, music/SFX, captions, render, delivery; AI asset packs | `complete-video-production/GUIDE.md` |
| Building or editing the animation itself with Remotion or HyperFrames (full nested reference tree) | `motion-graphics/GUIDE.md` |
| Same motion-graphics knowledge, flattened Lovable-friendly reference layout | `motion-graphics-lovable/GUIDE.md` |

Default: start with `complete-video-production` for whole videos; use `motion-graphics` for animation/technical details it delegates.
